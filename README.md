# SPOROCYST prototype

4フェイズの配置パズルでミラシジウムの貝への定着を目指し、定着後はスポロシスト群体を育て、超寄生によるセルカリアの品質低下を抑えながら次の宿主へ送り出す、二段階構成の短編ブラウザゲームです。

スポロシスト、セルカリア、超寄生などの用語と、ゲームが題材にしている吸虫の生活環については [USER_MANUAL.md](USER_MANUAL.md) を参照してください。

## 起動方法

依存パッケージやビルドは不要です。

1. `dist` フォルダごと保存して、`dist/index.html` をブラウザで直接開く
2. または、このフォルダで簡易HTTPサーバーを起動する

```bash
python3 -m http.server 8000 --directory dist
```

その後、`http://localhost:8000` を開いてください。

## ファイル

- `dist/index.html` — ゲーム画面と群体運営
- `dist/invasion.js` — 侵入・定着パズルと形質・損傷の引き継ぎ
- `dist/invasion.css` — パズルの盤面・操作表示
- `tests/invasion.test.cjs` — 第1ステージと群体運営への接続の回帰テスト
- `USER_MANUAL.md` — 生活環、用語、ゲーム内表現の解説
- `.openai/hosting.json` — ChatGPT Sites向け公開設定

## 注意

ゲーム内の数値は生物学的実測値ではなく、ゲーム性を確認するための仮想モデルです。


## 第1ステージの遊び方

外周12区画と内部9区画の同じ盤面を使います。操作はすべてクリック／タップで、時間制限はありません。

1. 表面認識：2区画のマスクを配置し、認識点を隠す。
2. 血球接着：予告に合わせて阻害片を置き、接着の包囲を切る。
3. 酸化攻撃：接着箇所からの酸化を、抗酸化片で中和する。
4. 母スポロシスト定着：経路を回転・修復し、栄養口から3つの胚へ栄養を届ける。

防御を厚くすると、群体運営で栄養吸収・維持費などのコストを負います。侵入損傷は生産休止や外皮調整で回復できます。初版は解法を学べる固定盤面です。

## テスト

ルールと群体運営への接続は追加依存なしで確認できます。

```bash
node --test tests/invasion.test.cjs
```
